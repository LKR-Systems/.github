## Über LKR-Systems

**LKR-Systems** ist das Label von Lukas Kretschmer für eigene IT-, Server- und Software-Projekte.
Hier entstehen und laufen Plattformen, Infrastruktur und Tools – von der Konzeption über den Aufbau bis zum laufenden Betrieb.
